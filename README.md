# Site ML Engenharia Civil

## Antes de publicar

O site está configurado para publicação, com WhatsApp, CREA, área de atendimento, foto profissional e serviços cadastrados.

Se precisar alterar o WhatsApp futuramente, edite `script.js` usando somente números, com `55` e DDD.

## Publicação mais barata

Use Cloudflare Pages gratuito para hospedar este site e registre um domínio `.com.br` no Registro.br. Faça upload desta pasta no GitHub, crie um projeto Pages apontando para o repositório e conecte seu domínio pelo menu `Custom domains` do Cloudflare.

Este site é estático: não exige servidor, banco de dados ou mensalidade de hospedagem.
